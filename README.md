# GreenMart Sales Dashboard

## Project Overview
This project analyses simulated supermarket sales data using Microsoft Excel. The dashboard helps identify sales trends, compare branch performance, and understand product category performance.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Dashboard visualisation

## Dataset
The dataset contains 65 simulated transactions from January to May 2026 across four supermarket branches.

## Key Findings
- Total sales: RM5,282.50
- Total transactions: 65
- Kajang recorded the highest branch sales.
- Beverage sales were the lowest among the four product categories.

## Files Included
- `GreenMart_Sales_Dashboard.xlsx` — Excel workbook and dashboard
- `GreenMart_Project_Report.pdf` — Project report and recommendations

Download the Excel workbook to explore the dashboard, PivotTables, and analysis. Open the PDF report to read the findings and recommendations.
